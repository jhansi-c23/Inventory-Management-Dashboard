# Inventory-Management-Dashboard
Inventory Management Dashboard built with Power BI to analyze inventory levels, revenue, gross margin, stock movement, and business performance through interactive visualizations.
## Overview

This project is an Inventory Management Dashboard developed using Power BI. The dashboard provides insights into inventory performance, revenue, gross margin, stock movement, and supplier-related metrics through interactive visualizations.

## Features

* Inventory On Hand Analysis
* Revenue Tracking
* Gross Margin Analysis
* Inventory Value Monitoring
* Sales and Receipts Tracking
* Quarter-wise Revenue Analysis
* Month-wise Revenue Trends
* Interactive Filters and Slicers
* KPI Cards and Visual Reports

## Tools Used

* Power BI Desktop
* DAX (Data Analysis Expressions)
* Power Query
* Data Modeling

## Data Model

The dashboard is built using multiple related tables:

* Calendar
* Products
* Suppliers
* Transactions

Relationships were created to enable efficient reporting and analysis across different dimensions.

## Key Metrics

* Revenue
* Gross Margin
* Gross Margin %
* Inventory On Hand
* Inventory Value
* Sales Quantity
* Receipts Quantity
* Net Movement
* Average Daily Demand
